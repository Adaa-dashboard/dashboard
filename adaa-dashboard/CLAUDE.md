# مشروع لوحة متابعة الأداء — أداء (Adaa Dashboard)

## نظرة عامة
لوحة متابعة HTML أحادية الملف (`project-dashboard.html`) لمشروع "دعم وتفعيل قياس وإدارة أداء الاستراتيجيات الوطنية والأداء المؤسسي" التابع لمركز أداء.
اللغة: عربي RTL بالكامل. الخط: IBM Plex Sans Arabic.

## معلومات المشروع الأساسية
- المدة: 15 شهراً (أبريل 2026 → يونيو 2027) — متغير `projectMonths` قابل للتعديل
- إجمالي العقد شامل الضريبة: 11,870,208 ر.س
- الفريق: عمر العتيق (مدير المشروع)، لمى المبدل، سلطانه العرجاني
- كل التفاصيل الكاملة في `project-info.md`

## المتغيرات الرئيسية في الكود
- `MP` — خطة الكميات الشهرية {شهر: [م1,م2,م3,م4]}
- `acts` — المنجز الفعلي (مصفوفة 15 شهر)
- `INV` — فواتير الصرف المخطط بدون ضريبة (15 قيمة)
- `TGT` — المستهدفات [60,290,1230,22]
- `UP` — أسعار الوحدة [81504,2400,768,172320]
- `MN` — أسماء الأشهر بالعربي
- `detCols` / `detRows` — جداول التفاصيل الأربعة
- `curM` — الشهر الحالي المحدد
- `paidMonths` — حالة الصرف الفعلي لكل شهر
- `actualPay` — قيم الصرف اليدوية (null = تلقائي)

## الصفحات الخمس
1. **الرئيسية** — شريط تقدم المشروع + المخطط مقابل المنجز (4 بطاقات) + ملخص الصرف + جدول المتابعة الشهري
2. **التقرير الشهري** — إدخال المنجز الفعلي + ملخص كل الأشهر
3. **التفاصيل** — 4 جداول قابلة للتعديل (لكل مخرج) مع فلتر وسحب وترتيب ولصق من Excel
4. **خطة الصرف** — الفواتير الـ15 قابلة للتعديل
5. **فريق المشروع** — modal

## ميزات مطبقة (لا تكسرها عند التعديل)

## أخطاء سابقة تم حلها (تجنب تكرارها)
1. مفاتيح كائن MP يجب أن تكون بصيغة JS (`1:`) وليس JSON (`"1":`)
2. لا تضع تعليقات عربية `//` داخل مصفوفات البيانات — سببت SyntaxError على iOS
3. عند استبدال دوال بـ regex تأكد من عدم ترك بقايا كود قديم بعد `}` — سببت "Unexpected token"
4. اختبر دائماً بـ `node --check` بعد أي تعديل على الـ JS

## سير العمل
1. عدّل `project-dashboard.html`
2. تحقق: `./check.sh` (يستخرج الـ `<script>` ويختبره بـ `node --check`)

4. (اختياري) رفع يدوي على Netlify بالسحب والإفلات
