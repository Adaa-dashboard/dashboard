# مولّد الدليل التشغيلي (غير مكتمل — بانتظار قرار الشكل)

رسم شاشات المنصة من `src/app/globals.css` نفسه، ثم تركيبها في PDF
مع أرقام على كل جزء ومفتاح تحته: من يراه ومن يعدّله.

## الملفات
- `mk.py` — يولّد ١٦ شاشة HTML من CSS المنصة (نظرة عامة · الأقسام الخمسة ·
  المؤشرات · المهام · التكاليف · طلبات التغيير · الأسبوعي · محفظتي ·
  المساعد الذكي · الملاحظات والتقويم · الهيكل · المستخدمون · الدخول)
- `spec.json` — محدّد CSS لكل جزء يُشرح في كل شاشة
- `measure.mjs` — يقيس مواضع تلك الأجزاء فعلياً في المتصفح ⇒ `pos.json`
  (المواضع مقيسة لا مخمَّنة — التخمين وضع النقاط في غير مكانها)
- `doc2.py` — يركّب الدليل HTML من الصور والمواضع
- `pdf.mjs` · `shotg.mjs` · `hh.mjs` — تصدير PDF · لقطات · فحص تجاوز الصفحة

## التشغيل
```
cd tools/guide
python3 mk.py            # يولّد s_*.html في مجلد العمل
node shotg.mjs s_*       # يلتقط s_*.png
node measure.mjs         # يقيس المواضع
python3 doc2.py          # يبني guide2.html
node pdf.mjs             # يصدّر PDF
```

## ما ينقص
1. **قرار الشكل والطول** — الإصدار الأول (٢٤ صفحة) والثاني (١٦) لم يُعتمدا.
2. **الصور الحقيقية** — بيئة التطوير محجوبة عن الشبكة الخارجية، فلا يمكن
   التقاط شاشات المنصة الحيّة. الصور الحالية مرسومة من CSS المنصة (الشكل
   مطابق، والبيانات توضيحية). البديل: تُلتقط الشاشات يدوياً وتُستبدل.
