# داشبورد متابعة إدارة استقطاب المواهب — مركز أداء

لوحة معلومات عربية (RTL) لمتابعة **التوظيف والتدريب والاستقالات والهيكل التنظيمي**،
بهوية مركز أداء، مع **إدخال وتعديل مباشر للبيانات** و**صلاحيات مستخدمين**.

---

## المحتويات

| الصفحة | ماذا تعرض |
|--------|-----------|
| **الرئيسية** | ملخّص مرئي لكل الأقسام: حالة طلبات التوظيف، حالة التدريب، الاستقالات حسب القطاع |
| **التوظيف** | نظرة عامة (حالة المقابلات + الشواغر والطلبات حسب القطاع) · جدول المقابلات · مراحل التوظيف الست + الانضمام |
| **التدريب** | حالة الطلبات · نسبة الإنجاز · توزيع المتدربين على القطاعات · جدول المتدربين |
| **الاستقالات** | التوزيع حسب الدرجة والقطاع · جدول الاستقالات |
| **القطاعات** | شجرة الهيكل التنظيمي بأي عمق: الشواغر (مشغولة/شاغرة) · المستوى الوظيفي (مبتدئ/متقدم) · الجنس — **مجمّعة تلقائيًا** على كل مستوى |

### المزايا
- **إدخال وتعديل مباشر** من داخل كل تبويب (زر إضافة + أيقونتا تعديل/حذف على كل بطاقة).
- **تعديل العناوين** من زر «تعديل العناوين» في أي صفحة، وتُحفظ في قاعدة البيانات.
- **فلاتر موحّدة**: القطاع/الإدارة · السنة · الشهر (اختياري).
- **صلاحيات ثلاث**: `owner` مالك الداشبورد (كل شيء + تعديل العناوين) — `editor` مُدخِل بيانات (إضافة/تعديل/حذف) — `viewer` عرض فقط للإدارة.
- **دخول برمز**: في الوضع المحلي يدخل المستخدم باسمه ورمز، والرمز هو ما يحدّد صلاحيته.
- تصميم متجاوب يعمل على الجوال والحاسب.

## التشغيل السريع (وضع تجريبي بدون قاعدة بيانات)

```bash
cd hr-dashboard
python3 -m http.server 8080
```
ثم افتح <http://localhost:8080> وأدخل اسمك ورمز الدخول.

| الرمز الافتراضي | الصلاحية |
|---|---|
| `4321` | مالك الداشبورد — كل الصلاحيات + تعديل العناوين |
| `1234` | مُدخِل بيانات — إضافة وتعديل وحذف |
| `1111` | عرض فقط — للإدارة |

> **غيّر هذه الرموز** من `assets/config.js` قبل التوزيع.
البيانات تُحفظ في متصفحك فقط (`localStorage`) — مناسب للتجربة والعرض.

## الربط بقاعدة البيانات (Supabase)

### ١) أنشئ المشروع والجداول
1. أنشئ مشروعًا مجانيًا على <https://supabase.com>.
2. افتح **SQL Editor → New query**، والصق محتوى [`supabase/schema.sql`](supabase/schema.sql) ثم شغّله.
   ينشئ الجداول، وسياسات الحماية (RLS)، والهيكل التنظيمي الابتدائي.

### ٢) اربط التطبيق
من **Project Settings → API** انسخ `Project URL` و `anon public key` وضعهما في
[`assets/config.js`](assets/config.js):

```js
window.APP_CONFIG = {
  SUPABASE_URL: "https://xxxxx.supabase.co",
  SUPABASE_ANON_KEY: "eyJhbGciOi...",
  ...
};
```

> `anon key` مفتاح عام وآمن للواجهة — الحماية الفعلية عبر سياسات RLS في قاعدة البيانات.

### ٣) أنشئ المستخدمين وحدّد صلاحياتهم
1. **Authentication → Users → Add user** (بريد + كلمة مرور).
2. من **Table Editor → profiles** عدّل الصف الخاص بالمستخدم:
   - `full_name`: الاسم الظاهر في أعلى الشاشة.
   - `role`: `owner` لمالك الداشبورد، أو `editor` لمُدخِل البيانات، أو `viewer` للإدارة (عرض فقط).

بمجرد ضبط `config.js` تتحوّل شاشة الدخول تلقائيًا إلى **بريد + كلمة مرور**.

## النشر

أي استضافة ملفات ثابتة تكفي (لا يحتاج خادم):

- **GitHub Pages**: Settings → Pages → Branch، ثم افتح `/hr-dashboard/`.
- **Netlify / Vercel**: اسحب المجلد أو اربط المستودع.
- **داخليًا**: انسخ المجلد على أي خادم ويب (IIS / Nginx / Apache).


## ملاحظات

- الهيكل التنظيمي الابتدائي **افتراضي للعرض** — عدّله من صفحة «القطاعات» أو مباشرة في قاعدة البيانات.
- مستهدف التدريب السنوي يُضبط من جدول `settings` (`training_target`).
- لتصفير البيانات التجريبية في المتصفح: نفّذ `DB.resetLocal()` من Console ثم حدّث الصفحة.
