# 📦 دليل التسليم — داشبورد متابعة إدارة استقطاب المواهب

مرحبًا بك 👋 هذا الملف يشرح لك كل ما تحتاجه لاستلام الداشبورد وتشغيله ونشره.

---

## ١) ما الذي استلمته؟

داشبورد عربي (من اليمين لليسار) بهوية مركز أداء، يتكوّن من **خمس صفحات**:

| الصفحة | المحتوى |
|--------|---------|
| **الرئيسية** | ملخّص مرئي: حالة طلبات التوظيف · حالة التدريب · الاستقالات حسب القطاع |
| **التوظيف** | نظرة عامة · جدول المقابلات · مراحل التوظيف الست ومرحلة الانضمام |
| **التدريب** | حالة الطلبات · نسبة الإنجاز · توزيع المتدربين · جدول المتدربين |
| **الاستقالات** | التوزيع حسب الدرجة والقطاع · جدول الاستقالات |
| **القطاعات** | شجرة الهيكل التنظيمي بأي عمق، والإحصائيات تُجمَّع تلقائيًا على كل مستوى |

**المزايا:**
- إضافة وتعديل وحذف مباشر من داخل كل تبويب.
- ثلاث صلاحيات: مالك · مُدخِل بيانات · عرض فقط.
- فلاتر: القطاع/الإدارة · السنة · الشهر.
- يعمل على الجوال والحاسب.

> **البيانات الحالية تجريبية** لتشوف الشكل النهائي — احذفها واستبدلها ببياناتك متى ما بدأت.

## ٢) التشغيل السريع (تجربة فورية)

**أسهل طريقة:** افتح ملف `standalone.html` بأي متصفح (Chrome أو Safari) — يعمل مباشرة بدون إنترنت.

**الطريقة الكاملة:**
```bash
cd hr-dashboard
python3 -m http.server 8080
```
ثم افتح <http://localhost:8080>

**رموز الدخول:**

| الرمز | الصلاحية |
|-------|----------|
| `4321` | مالك الداشبورد — كل الصلاحيات + تعديل العناوين |
| `1234` | مُدخِل بيانات — إضافة وتعديل وحذف |
| `1111` | عرض فقط — للإدارة |

### 🔐 أول شيء تسويه: غيّر الرموز
افتح `assets/config.js` وعدّل الأرقام هنا:
```js
ACCESS_CODES: {
  owner:  "4321",   // ← غيّره
  editor: "1234",   // ← غيّره
  viewer: "1111",   // ← غيّره
},
```

## ٣) نشره على الإنترنت (رابط دائم مجاني)

1. أنشئ مستودعًا جديدًا في حسابك على <https://github.com> (اجعله **Public**).
2. ارفع محتويات مجلد `hr-dashboard` فيه (زر **Add file → Upload files**).
3. من **Settings → Pages**:
   - **Source**: `Deploy from a branch`
   - **Branch**: `main` والمجلد `/ (root)`
   - اضغط **Save**
4. بعد دقيقة يصير رابطك:
   `https://<اسم-حسابك>.github.io/<اسم-المستودع>/`

> ⚠️ لا تحذف ملف `.nojekyll` — بدونه لن تظهر الصفحة بشكل صحيح.

## ٤) البيانات: أين تُحفظ؟

### الوضع الحالي (بدون إعداد)
البيانات تُحفظ **في متصفح كل شخص على حدة**. مناسب للتجربة، لكن لا يشارك أحد بيانات أحد.

### للاستخدام الفعلي المشترك (مستحسن)
اربطه بقاعدة بيانات مجانية — الخطوات كاملة في `README.md`، وباختصار:
1. أنشئ مشروعًا على <https://supabase.com> (مجاني).
2. من **SQL Editor** الصق محتوى `supabase/schema.sql` وشغّله — ينشئ الجداول والحماية.
3. من **Project Settings → API** انسخ `Project URL` و `anon key` وضعهما في `assets/config.js`.
4. أنشئ حسابات المستخدمين من **Authentication**، وحدّد صلاحية كل واحد في جدول `profiles`
   (`owner` أو `editor` أو `viewer`).

بعدها: البيانات مشتركة بين الجميع، والدخول ببريد وكلمة مرور بدل الرمز.

## ٥) أين أعدّل كل شيء؟

| ما تريد تغييره | الملف | التفاصيل |
|----------------|-------|----------|
| **رموز الدخول** | `assets/config.js` | `ACCESS_CODES` |
| **اسم الجهة** أعلى الصفحة | `assets/config.js` | `ORG_NAME` |
| **السنوات في الفلتر** | `assets/config.js` | `YEARS` |
| **الألوان** | `assets/base.css` | المتغيرات في `:root` (تبدأ بـ `--g-`) |
| **البيانات الابتدائية** | `assets/data.js` | الكائن `SEED` |
| **حقول النماذج** | `assets/app.js` | الكائن `FORMS` |
| **صفحة جديدة** | `assets/app.js` | أضف دالة عرض ثم سجّلها في `PAGES` |
| **الشعار** | `assets/adaa-logo.png` | استبدل الصورة بنفس الاسم |

**العناوين داخل الشاشات** تُعدَّل من التطبيق نفسه: ادخل بصلاحية المالك → زر **«تعديل العناوين»** → عدّل → احفظ.

```

├── index.html              ← الصفحة الرئيسية للتطبيق
├── standalone.html         ← نسخة بملف واحد (للعرض السريع)

├── assets/
│   ├── config.js           ← ⚙️ الإعدادات (ابدأ من هنا)
│   ├── base.css            ← تصميم الهوية والألوان
│   ├── app.css             ← الدخول والنماذج وواجهة الجوال
│   ├── data.js             ← البيانات والصلاحيات
│   ├── app.js              ← المنطق والرسوم والصفحات
│   └── adaa-logo.png       ← الشعار
└── supabase/
    └── schema.sql          ← مخطّط قاعدة البيانات
```

## ٧) أسئلة متوقعة

**هل يحتاج خادمًا أو تنصيبًا؟**
لا — ملفات HTML/CSS/JS عادية. أي استضافة ملفات ثابتة تكفي.

**هل يعمل على الجوال؟**
نعم، بواجهة مخصصة: شريط تنقّل سفلي، وبطاقات ونماذج مهيّأة للشاشات الصغيرة.

**كيف أصفّر البيانات التجريبية؟**
افتح Console في المتصفح واكتب `DB.resetLocal()` ثم حدّث الصفحة.
أو احذفها من داخل التطبيق بأيقونة 🗑 على كل سجل.

**هل أقدر أطوّره بمساعدة الذكاء الاصطناعي؟**
نعم — ارفع المجلد في محادثة واطلب التعديل، أو اربط المستودع بـ Claude Code وأعطه هذا الدليل كنقطة بداية.
