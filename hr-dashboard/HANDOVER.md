# تسليم المشروع — داشبورد متابعة إدارة استقطاب المواهب

## ما هذا المشروع؟
تطبيق ويب عربي (RTL) بخمس صفحات: الرئيسية · التوظيف · التدريب · الاستقالات · القطاعات.
**ملفات ثابتة فقط** — لا يحتاج Node ولا بناء ولا خادم. يكفي فتح `index.html` عبر خادم بسيط.

## التشغيل محليًا
```bash
cd hr-dashboard
python3 -m http.server 8080
# ثم افتح http://localhost:8080
```
رموز الدخول الافتراضية: `4321` مالك · `1234` مُدخِل بيانات · `1111` عرض فقط
(تُغيَّر من `assets/config.js`)

## الملفات ووظائفها
| الملف | الوظيفة |
|---|---|
| `index.html` | هيكل الصفحة وتحميل الملفات |
| `assets/base.css` | تصميم الهوية (ألوان أداء، البطاقات، الرسوم) |
| `assets/app.css` | الدخول، النماذج، واجهة الجوال |
| `assets/config.js` | **الإعدادات**: رموز الدخول، بيانات Supabase، السنوات |
| `assets/data.js` | طبقة البيانات: Supabase أو تخزين محلي + الصلاحيات |
| `assets/app.js` | المنطق: الصفحات، الرسوم، النماذج، الفلاتر |
| `supabase/schema.sql` | مخطّط قاعدة البيانات + سياسات الحماية |
| `standalone.html` | نسخة بملف واحد (كل شيء مضمّن) للعرض السريع |

## أين تعدّل ماذا؟
- **نصوص وعناوين**: من التطبيق نفسه (زر «تعديل العناوين» لصلاحية المالك).
- **رموز الدخول**: `assets/config.js` → `ACCESS_CODES`.
- **الألوان**: `assets/base.css` → المتغيرات في `:root` (تبدأ بـ `--g-`).
- **بيانات ابتدائية**: `assets/data.js` → الكائن `SEED`.
- **صفحة جديدة**: `assets/app.js` → أضف دالة عرض ثم سجّلها في `PAGES`.
- **حقول نموذج**: `assets/app.js` → الكائن `FORMS`.

## الربط بقاعدة بيانات (اختياري)
1. أنشئ مشروعًا على supabase.com.
2. شغّل `supabase/schema.sql` في SQL Editor.
3. ضع `SUPABASE_URL` و `SUPABASE_ANON_KEY` في `assets/config.js`.
4. أنشئ المستخدمين من Authentication، وحدّد `role` لكل واحد في جدول `profiles`
   (`owner` / `editor` / `viewer`).

بدون هذه الخطوة يعمل التطبيق بتخزين محلي في المتصفح (مناسب للتجربة).

## النشر على GitHub Pages
1. ارفع المجلد على مستودعك.
2. Settings → Pages → Deploy from a branch → `main` → `/ (root)` → Save.
3. الرابط: `https://<اسم-المستخدم>.github.io/<اسم-المستودع>/hr-dashboard/`

> ملف `.nojekyll` مهم — لا تحذفه، فهو يمنع GitHub من معالجة الملفات.
